# MOBA 技能栏

在 Windows 11 上双击 `run.bat` 启动。需要 .NET 8 SDK，首次构建会从 NuGet 下载依赖。

1. 点击 **框选技能格**，左键拖出要预览的范围。放大镜会显示光标附近的像素和框选边缘。拖动前或拖动中可用 **WASD** 或**方向键** 每次移动鼠标 1 个像素，右键或 **Esc** 取消。
2. 点击悬浮栏里的技能格选中它。编辑时，从悬浮栏空白处按住左键拖动，或在未选中的技能格上长按约 0.4 秒再拖动，即可框选与选框相交的格子。拖动任一选中格可整体移动，长按也可继续拖动。选中后按 **WASD** 或**方向键**，每次移动 1 个物理像素。列表中各格的 X、Y 以悬浮栏内容区左上角为原点，单选时悬浮栏顶部也显示坐标。单选时拖动边框控制点可以等比缩放。拖住悬浮栏顶部可以移动整栏。
3. 选中已有技能格后可重命名，也可调整缩放、透明度、对比度、色度或叠放顺序。双击数值可全选并输入百分比，按 Enter 或移开焦点提交，按 Esc 撤销本次输入。每行右侧的 **复位** 恢复该项默认值。色度为 0% 时显示黑白，100% 时显示原色。点击 **完成编辑** 后，技能格留在原处，鼠标可以点到下方应用。

在控制窗口点击 **隐藏悬浮栏** 可暂停预览，再点击 **显示悬浮栏** 即可恢复。此开关在编辑模式和显示模式下都可使用。

从源码启动时，布局自动读写仓库根目录的 [config/layouts.json](config/layouts.json)。独立发布版读写程序旁的同名文件。该文件缺失时，程序会尝试从旧用户目录导入布局。同一显示器上的相邻技能格共用一个读回区域。预览目标为 60 FPS，实际帧率取决于源画面、桌面合成节奏和系统负载。

应用源码和 OpenSpec 位于 `source/`。从该目录运行 `openspec list` 可查看正在进行的变更。
