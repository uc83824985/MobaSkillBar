# MOBA 技能栏

在 Windows 11 上双击 `run.bat` 启动。需要 .NET 8 SDK，首次构建会从 NuGet 下载依赖。

1. 点击 **框选技能格**，在游戏画面上拖出要预览的范围。
2. 点击悬浮栏里的技能格选中它。拖动格子可以移动位置，拖动边框控制点可以等比缩放。拖住悬浮栏顶部可以移动整栏。
3. 在控制窗口调整透明度、对比度或叠放顺序。点击 **完成编辑** 后，技能格留在原处，鼠标可以点到下方应用。

各布局自动保存在 `%LOCALAPPDATA%\MobaSkillBar\layouts.json`。同一显示器上的相邻技能格共用一个读回区域。预览目标为 60 FPS，实际帧率取决于源画面、桌面合成节奏和系统负载。

应用源码和 OpenSpec 位于 `source/`。从该目录运行 `openspec list` 可查看正在进行的变更。
